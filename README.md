# Hadisa Abroo, portfolio website

Live at https://hadisaabroo99-pixel.github.io/Graphic_Portfolio/

## Update the site (one time)

1. Unzip `hadisa-portfolio.zip`.
2. In the Graphic_Portfolio repository, click **Add file > Upload files**.
3. Open the unzipped folder, select everything inside it (including the `work` folder) and drag it into the upload box.
4. Click **Commit changes**. Files with the same name are replaced automatically.

## Add your work (no code needed)

Put images into the right folder and upload. They appear on the site by themselves.

| Folder | Shows under |
|---|---|
| work/packaging | Packaging |
| work/labels | Labels |
| work/branding | Branding |
| work/social-media | Social media |
| work/web | Web |

The easiest way: on your computer, copy your images into these folders inside the unzipped `work` folder, then drag the whole `work` folder onto the GitHub upload page and commit.

- The file name becomes the title. `aveir-hair-oil.jpg` shows as "Aveir hair oil".
- Put numbers at the start to control the order: `01-aveir-hair-oil.jpg`, `02-sknly-boxes.jpg`.
- Portrait images (4:5) look best. Keep each under about 500 KB.
- A category with no images is hidden. If there are no images at all, sample tiles show.
- New uploads appear within a minute or two. Press Ctrl+Shift+R to refresh.

## Update your CV

Upload a new PDF named exactly `Hadisa_Abroo_CV.pdf`. It replaces the old one everywhere.
